# Martin Pazmiño – Portfolio

Personal portfolio built with [Streamlit](https://streamlit.io): digital construction, BIM, tunnelling data,
GIS and parametric design.

## Pages

- **About Me**: current focus, background and languages
- **Experience**: Wayss & Freytag (working student, internship semester), earlier internships and education
- **Projects**: 2025–2026 work (TBM → BIM viewer, equipment zones in Revit, bachelor thesis, UAV/QGIS,
  parametric urban model, machine learning, automation side projects) and earlier projects
- **Skills**: tools, methods, languages and certificates
- **Contact**

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

The colour theme lives in `.streamlit/config.toml`; images, videos and certificates are in `static/`.
